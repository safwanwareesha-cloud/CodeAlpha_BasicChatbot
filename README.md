Basic Chatbot 🤖

A simple rule-based chatbot built using Python. The chatbot interacts with the user through the console and provides predefined responses to common messages.

Features
Responds to greetings
Responds to "how are you"
Provides a goodbye message
Uses predefined responses
Runs continuously until the user types "bye"
Simple console-based interaction
Technologies Used
Python
Functions
If-elif-else statements
While loops
User input and output
Strings
How to Run

Make sure Python is installed on your computer.

Run the following command:

python main2.py

If python doesn't work, try:

py main2.py
How to Use

Start the program and type a message.

Example:

Chatbot: Hi! I am a simple chatbot.
Chatbot: Type 'bye' to exit.

You: hello
Chatbot: Hi!

You: how are you
Chatbot: I'm fine, thanks!

You: bye
Chatbot: Goodbye!
